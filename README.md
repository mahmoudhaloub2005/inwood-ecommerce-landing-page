# INWOOD Furniture eCommerce Landing Page

A responsive static implementation of the INWOOD furniture eCommerce landing page using HTML5, CSS3, and Vanilla JavaScript.

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts: DM Sans and Playfair Display

## Project Structure

```text
/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
├── assets/
│   ├── images/
│   ├── icons/
│   └── fonts/
└── README.md
```

## Run Locally

Open `index.html` directly in a browser. No build step or framework is required.

## Responsive Support

The layout is tuned for desktop, tablet, and mobile widths, including approximately 1440px, 1280px, 1024px, 768px, 430px, 390px, 375px, and 320px.

## Asset Notes

The Figma connector was not available as a callable tool in this environment after installation was requested, so exact Dev Mode measurements and direct Figma exports could not be extracted. The implementation uses local INWOOD imagery from a public matching reference repository for the same design (`https://github.com/mclegacycodes/inwood`), copied into `assets/images/`, and avoids random stock-photo replacements.
